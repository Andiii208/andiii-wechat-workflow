# Andiii 水彩风格引擎 v1.0

把用户的主题/句子/情绪编译成**手绘水彩风**的图生 prompt（封面/内文配图/金句卡），生成对应栅格图。

**引擎哲学**：只锁三件事——配色、纹理、排版。隐喻转译与构图自由发挥（用户偏好 AI 自由发挥，拒绝套路化）。风格可替换：换风格只需换引擎文件（色彩/纹理/排版/规避四件套），管线不动。

## 硬输入（用户已确认的审美基线）

- ✅ 手绘水彩风：纸纹、笔触、晕染（水彩边缘晕开）
- ✅ 简约感·艺术感·高级感；低饱和暖调
- ❌ flat 极简线稿、炭黑金海报、美术馆海报风、玻璃拟态、渐变紫、3D、霓虹、日系插画模板脸
- 📐 封面标题文字居中安全区（微信 1:1 裁切不截断）
- 🖼 内文配图全部 16:9 横构图

## 一、色彩引擎（默认策略）

- **基底**：暖米色纸系（米白/浅燕麦/暖灰），占画面 **55%-75%**
- **晕染色**：1-2 个低饱和水彩主色，从这组选：鼠尾草绿 / 陶土橙 / 雾霾蓝 / 旧黄（褪色黄）/ 干枯玫瑰
- **墨色**：深灰暖棕，低对比，不用纯黑
- **存在形式**：晕染色以水彩湿画法晕染、色带、洗淡照片区存在——**禁止平涂色块**
- **量化**：晕染区合计占画面 10%-25%，任何单色块 <5%

**禁用词（prompt 里禁止出现）**：`flat vector`、`minimalist line art`、`charcoal`、`gold foil`、`gallery poster`、`vivid gradient`、`glassmorphism`、`neon glow`、`3D render`、`anime style`、`swiss grid`、`matte poster`、`high saturation`、`clean white background`

## 二、纹理引擎（纸感词表）

每个 prompt 必须包含 **≥2 个纹理词 + 1 个纸感词**：

| 类别 | 词（中英对照） |
|---|---|
| 纸感 | cold-pressed paper texture 冷压水彩纸纹 / aged paper 旧纸 / paper fiber 纸纤维 / washi paper 和纸 |
| 晕染 | wet-on-wet blooms 湿接湿晕染 / watercolor edge bleeding 水痕边缘渗开 / washed-out edges 边缘洗淡 / color bloom 色花 |
| 笔触 | visible brush strokes 可见笔触 / dry brush 干笔触 / loose strokes 松散笔触 |
| 颗粒 | granulating pigments 颗粒沉淀颜料 / subtle paint splatter 轻微溅墨 / paper grain 纸颗粒 |

## 三、排版引擎（封面标题规则）

- **标题字数**：中文 ≤10 字；英文 ≤4 词。长标题拆副题或放弃图内文字
- **⛔ 图内标题 vs 平台标题双轨（2026-08-03 修）**：图内文字必须 = 平台标题的短版（≤10 字截取）或用户指定的意象词——**禁止自创与平台标题无关的文字**（读者会困惑）。输出格式里必须同时列出「图内文字」与「平台标题」供用户核对
- **安全区**（2026-08-03 实测放宽）：标题水平居中；左右各留 **≥15%** 边距；垂直 **25%-60% 可接受**（优先 40%-60%）——Wan2.7 倾向把标题贴着主体构图，无法稳定居中；**硬性要求是标题完整清晰 + 左右留边够**（朋友圈/分享卡片 1:1 不裁切，垂直偏差不致命）
- **字体**：`handwritten Chinese calligraphy`（手写感）或 `Song-style serif`（宋体），深灰墨色
- **字号**：标题为画面第二大的元素（仅次于留白），副题/落款小号灰墨
- **无标题变体**：纯视觉图（`--text none`）允许，用于内文配图与金句卡

### 封面双尺寸协议

| 用途 | 比例 | 标题位置 |
|---|---|---|
| 公众号首图（列表+打开页） | **16:9 生成 → 中心裁 2.35:1 ≈ 900×383 交付** | 居中偏上（垂直 30%-45%），左右 ≥15% |
| 分享图（朋友圈/转发卡片） | **1:1** | 居中优先（垂直 25%-60% 可接受），左右 ≥15%，标题完整清晰 |

**⛔ 封面安全区设计（2026-08-03 实测教训）**：2.35:1 裁剪要砍掉 24% 高度，中心裁切标题完整但切主体、底部锚点保主体但切标题——**必须靠生成时预留安全区**，不是靠裁剪锚点。封面 prompt 的 P1 必须附加安全区约束句：

```text
构图安全区：主体簇与标题文字全部位于画面垂直中心带（25%-75%），画面顶部 15% 与底部 15% 保持纯纸色留白（无任何内容），便于安全裁切
```

同一 prompt 出两版（只改画布比例声明）。两版文件：`cover.jpg`（2.35:1 交付，中心裁剪）+ `cover-square.jpg`（1:1）。封面/配图统一 **.jpg 扩展名**（PIL 存 JPEG 内容命名 .png 会触发 wechat-api "Format mismatch" 警告）。裁剪用 `scripts/crop_image.py`。

## 四、规避清单（反 AI 味检查门）

### 硬规避（命中即 FAIL，必须重写 prompt）

- 全出血商业海报 / 广告标题层级 / logo / CTA
- 玻璃拟态、渐变紫、霓虹、3D 渲染、电影感打光、景深
- 日系动漫脸、可爱卡通、时尚杂志大片感
- 高饱和色块、炭黑金、美术馆海报风
- 干净 UI 白底、完美无瑕的矢量插画

### 软规避（命中即 WARN，能改则改）

- `high saturation`、`gradient`、`drop shadow`、`bokeh`、`photo-realistic`、`stock photo`、`clean white background`

## 五、四段式 prompt 编译模板

所有配图统一走这个形状（用结构，不用样例词）：

```text
P1 画布与纸感: [比例 16:9/1:1/21:9] 全幅[纸色]底, [留白比例]留白, [纸感词]+[纹理词×2], 主体簇位于[位置: 中/下左/上右…], 占画面[比例]
P2 主体隐喻: [主题转译的意象]（[锚点类型: 旧照片/剪纸/标本/剪影/水彩晕染物]）, [锚点处理: 边缘渗开/洗淡/纸感/笔触]
P3 文字与色彩: [标题或说明文字, 字体, 位置], [晕染色1]+[晕染色2] 以[湿画法/晕染带/洗淡照片区]存在, [纸缺陷: 轻微溅墨/水痕/纤维]
P4 氛围与规避: 安静的、诗意的、日记感的、记忆感的, 避免[命中规避项]
```

**转译规则**（P2 是唯一自由发挥点）：
- 把抽象主题转成一个可画的具体意象（不是场景堆砌）
- 一个隐喻 > 三个元素；宁缺毋滥
- 例：孤独 → 一扇半开的窗，窗帘被风吹起一角；疲惫 → 桌上一杯凉透的茶，杯沿一圈茶渍

## 六、工作流

1. **加载弹药库**：`references/watercolor-prompt-library.md` 按主题找模板（有匹配主题 → 取模板填槽；无 → 直接编译）
2. **转译主题**：解析用户内容 → 核心意象 + 情绪 + 可选文字（P2）
3. **编译四段式 prompt**：按模板形状写，禁止整段复制样例
4. **质检门**：
   ```bash
   echo "prompt内容" | python scripts/check_engine_prompt.py
   ```
   - FAIL → 改 prompt 直到 PASS；WARN → 尽量消除
   - **PASS 才允许调图生后端**
5. **生成**：
   - 封面 → 内置 image_generate（Wan2.7-Image，主力）：先 16:9（附加安全区约束句）再 1:1 两版
   - 内文配图 → 16:9 横构图，prompt 显式锚定横向元素
   - 金句卡 → 1:1
6. **出图后视觉复核（MiMo v2.5 自动，2026-08-03 接入）**：
   - 调用 vision_analyze 固定问句检查：①标题完整无错字 ②标题左右留边 ≥15% ③主体完整未被裁切 ④无硬雷区（高饱和/玻璃拟态/霓虹灯/3D）
   - 任一 FAIL → 收紧 prompt 重生成一次（改文字密度/位置表述/换弹药库模板）；再 FAIL 才给用户看并说明
   - 视觉复核 PASS → 交用户**最终确认**（审美判断：晕染美不美、构图喜不喜欢——视觉模型不评审美，结论以用户为准）
   - ⚠️ 视觉模型只做硬检查（错字/被裁/雷区），误判时以用户为准（2026-08-03 1:1 标题位置即被用户纠正过）

## 七、金句卡规格

- 尺寸 **1:1**，插入文末（`就到这里，下次见。` 之前）
- 内容：正文**原句** 1 句（≤20 字，不得编造/改写），+ 落款「——Andiii碎碎念」
- **⛔ 金句不重复（2026-08-03 修）**：金句卡句子不得与正文引用块/加粗金句/结尾金句重复——同一句全文只出现一次（正文引用 or 金句卡，二选一）。全文只有一句金句时：金句卡改用另一句次金句，或出**纯意象卡**（无文字，只用水彩意象）
- 视觉：水彩底 + 手写感大字 + 留白 >60%，复用四件套
- 来源标注：图下说明文字写「摘自《标题》」
