# Andiii 水彩 prompt 弹药库

按主题分类的水彩配图模板。**用结构不用样例词**：模板是槽位框架，生成时填槽 + 换 P2 隐喻，禁止整段复制（防同质化）。

用法：写 prompt 前查本库 → 匹配主题 → 取模板 → 填 `{槽位}` → 换 P2 隐喻 → 过质检门。

## 附录：水彩专业词汇（中英对照）

| 词 | 中文 | 生效语境 |
|---|---|---|
| cold-pressed paper texture | 冷压纸纹 | 纸感基底，Wan2.7 ✅ |
| aged paper / old paper | 旧纸 | 纸感基底 |
| paper fiber | 纸纤维 | 加强纸感细节 |
| wet-on-wet blooms | 湿接湿晕染 | 晕染主技法 |
| watercolor edge bleeding | 边缘渗开 | 主体边缘处理 |
| washed-out edges | 边缘洗淡 | 主体边缘处理 |
| visible brush strokes | 可见笔触 | 手绘感 |
| dry brush | 干笔触 | 质感细节 |
| loose strokes | 松散笔触 | 自由感 |
| granulating pigments | 颗粒沉淀 | 水彩特有质感 |
| subtle paint splatter | 轻微溅墨 | 纸缺陷点缀 |
| paper grain | 纸颗粒 | 颗粒感 |
