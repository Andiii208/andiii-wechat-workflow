# Andiii 喜茶风（新中式茶饮）风格引擎 v1.0

## 零、风格是参考，不是限制（用户 2026-08-03 明确）

本引擎的视觉规则是**灵感起点**，不是约束框：
- 默认按本引擎四件套走（保证气质底线）
- 但允许**跨风格借用 / 混搭 / 偏离**——当主题或用户意图更适合时（如喜茶底 + 极简构图、zine 拼贴 + 一处水彩晕染、潦草线条 + 水墨质感）
- 质检门（质感/雷区底线）仍然生效；**风格本身是软的**
- 目的：以风格激发更多创意，不是按模板死板执行

## 一、风格定位

**新中式茶饮美学——克制的东方感，不是网红奶茶店风。**

喜茶风的本质是"留白与茶气"：像一间安静的茶室，纸是宣纸、色是茶汤、墨是笔意，一切都在低饱和的暖调里慢慢晕开。它区别于网红奶茶店风（高饱和粉/渐变紫/塑料杯/吸管特写/霓虹灯牌）——喜茶风没有"奶茶"，只有"茶"；没有"店"，只有"席"。

与 andiii-image-style（手绘水彩）的区别：水彩是"湿的、晕染的、柔软的"；喜茶风是"纸的、茶的、留白的"——更素、更慢、更克制，靠大面积纸色留白与少量墨色茶渍建立呼吸感。

适合：生活美学/日常/情绪/茶与慢生活/节气/独处/旧物类文章。

## 二、四件套引擎

### 1. 色彩（Color Logic）
- **基底**：米白/宣纸色/牛皮纸色（暖调纸色，占画面 70% 以上）
- **主体色**：茶汤色（浅褐/金棕），用于主体意象
- **骨架色**：墨色（灰黑带暖），用于笔触、线条、阴影
- **点缀色**：至多一个，低饱和——黛青或胭脂，小面积出现（印章、叶、茶点）
- **整体**：低饱和暖调；禁止高饱和霓虹色、渐变紫、荧光感
- **措辞**：写 `muted warm palette with [paper tone] base and a hint of [accent]`，不写 vivid/saturated/high-chroma

### 2. 纹理（Texture）
- 宣纸纹理、水墨晕染、茶渍晕圈、印章（朱砂印泥）、纸纤维、水痕渗开、墨迹淡开
- 硬性要求：每个 prompt **≥2 个纹理词 + 1 个纸感词**（质检门硬校验）

### 3. 排版（Typography）
- **默认无图内文字**（andiii 工作流原则，文案由公众号排版承载）
- 仅用户明确要求时才加文字：书法字/宋体竖排短句 + 印章落款元素；文字低对比、半可读、不超过 6 字

### 4. 规避（Hard Avoids，硬雷区）
flat vector、minimalist line art、charcoal、gold foil、gallery poster、vivid gradient、glassmorphism、neon glow、3d render、anime style、塑料奶茶杯、吸管特写、网红奶茶店风、高饱和、渐变紫、日系动漫、卡通、玻璃拟态、霓虹灯、全出血

## 四、变体引擎（Variation Engine）

每个轴选一项，随机性必须改变视觉语法（不只换位置）。连续出图避免雷同：

- **布局（Layout）**：中置茶器 / 左下浮空 / 右上印章位 / 茶碗同心圆 / 竖轴留白 / 窗式裁切 / 对角线留白 / 大字让位
- **锚点（Image Anchor）**：盖碗茶 / 茶汤涟漪 / 茶芽与茶叶 / 宣纸墨点 / 朱砂印章 / 茶点（桂花糕）/ 茶席器物 / 雾气与杯沿
- **文字模式（Typography Mode）**：无文字（默认）/ 竖排宋体短句 / 书法单字 / 印章落款 / 纸签小字 / 半可读微字
- **纹理（Texture Mode）**：水墨晕染 / 茶渍晕圈 / 宣纸纤维 / 印章朱砂 / 水痕渗开 / 墨迹淡开 / 纸面颗粒
- **情绪（Mood Mode）**：静谧 / 雨天 / 独处 / 怀旧 / 四季 / 清冷 / 温润 / 松弛

## 六、工作流（Andiii 适配层）

0. **设计推理（必做，≤60秒）**：读 `D:/tools/andiii-wechat-workflow/references/design-reasoning.md`，按 6 项模板作答（用途渠道/受众气质/视觉系统/主次层级/留白决策/方向承诺）——先定「为什么这么画」，再动手编译
1. **转译**：把文章主题/情绪转成茶席意象（P2 隐喻是自由发挥点，不写场景堆砌）
2. **选变体**：Layout / Anchor / Typography / Texture / Mood 各选一项
3. **编译**：按四段式模板出完整 prompt（含 P1 安全区约束句）
4. **质检门**：`echo "prompt" | python D:/tools/hermes/skills/creative/andiii-image-style/scripts/check_engine_prompt.py`（PASS 才生成；宣纸/水墨/茶渍/印章天然满足纸感+纹理要求。注意：词表权威版在仓库 andiii-image-style，hermes 副本由主 agent 同步后才会含喜茶系词——同步前 5.3/5.4 模板仍可过门，因已内建晕染/渗开/水痕等通用纹理词）
5. **生成**：封面 16:9 → 中心裁 2.35:1；分享图 1:1；内文配图 16:9
6. **视觉复核**（固定问句）：主体完整未裁切 / 无硬雷区 / 水墨晕染与茶渍纹理明显；封面裁后必复核
7. **用户确认**：交用户最终确认（审美以用户为准）
