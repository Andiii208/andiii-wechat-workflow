# 喜茶风（新中式茶饮）风格细节指南

配套 `andiii-heytear-style` 引擎的参考手册：色值、元素、构图、质感词、避雷清单与文字规则。写给人类与模型共读，供编译 prompt 与视觉复核时对照。

## 一、色值描述（低饱和暖调）

| 角色 | 名称 | 参考色值 | 说明 |
|---|---|---|---|
| 基底 | 宣纸白 | #F3EDE0 | 暖调米白，默认主底，占画面 70%+ |
| 基底 | 牛皮纸色 | #E8DCC4 | 偏黄旧纸感，独处/旧物主题常用 |
| 基底 | 旧纸色 | #EFE6D3 | 微瑕纸色，雨天/怀旧主题 |
| 主体 | 茶汤浅褐 | #C9A17C | 浅泡茶汤色，主体意象主色 |
| 主体 | 茶汤金棕 | #A67C52 | 深泡/老茶汤色 |
| 骨架 | 墨色 | #33302B | 灰黑带暖，笔触/线条/阴影 |
| 点缀 | 黛青 | #4E5E6D | 低饱和灰蓝绿，印章/叶/远山 |
| 点缀 | 胭脂 | #B26A5C | 低饱和灰红，印泥/茶点/花瓣 |
| 点缀 | 竹青 | #7C8F6E | 夏季替代点缀 |
| 点缀 | 冬灰蓝 | #8A97A3 | 冬季替代点缀 |

**规则**：纸色 ≥70% 画面；点缀色 ≤5% 画面；全画面色相不超过 3 个；任何颜色都要"灰一点、暖一点"。禁：荧光、霓虹、高饱和纯色、渐变紫。

## 二、元素库

- **器物**：盖碗、紫砂壶、玻璃杯、粗陶盏、茶则、茶托、竹席、粗陶罐
- **茶**：茶汤、茶芽、茶叶、茶渍、茶点（桂花糕/绿豆糕/柿饼）
- **纸墨**：宣纸、墨点、水墨晕染、书法字、朱砂印章、纸纤维
- **氛围**：雾气、杯沿热气、窗影、雨丝、斜照光线、大块留白
- **隐喻**：茶汤当湖面、墨点当远山、茶渍当记忆、茶气当思绪

## 三、构图与留白

- 留白 70%–90%，单个视觉簇占 8%–25%
- 常用位置：中下 / 左下 / 右上（印章位），不贴边
- 主体单一：最多两个意象（一主一辅），拒绝场景堆砌
- 主体处理：水墨晕染边缘、茶渍渗开、墨色淡开、留白收边

## 四、质感关键词（可直接进 prompt）

宣纸纹理 / 水墨晕染 / 茶渍晕圈 / 印章 / 纸纤维 / 水痕渗开 / 墨迹淡开 / 纸面颗粒 / 哑光 / 印泥痕迹

**质检门硬性要求**：每个 prompt ≥2 个纹理词 + 1 个纸感词（宣纸/牛皮纸/旧纸/纸纹/纸纤维均可）。

## 五、避雷清单（硬雷区，进 prompt 时以"避免X"前缀豁免）

flat vector、minimalist line art、charcoal、gold foil、gallery poster、vivid gradient、glassmorphism、neon glow、3d render、anime style、塑料奶茶杯、吸管特写、网红奶茶店风、高饱和、渐变紫、日系动漫、卡通、玻璃拟态、霓虹灯、全出血、mockup、logo、CTA

**为什么**：
- **塑料奶茶杯 / 吸管特写**：网红奶茶店风的第一视觉符号，直接毁掉东方感
- **高饱和 / 渐变紫**：喜茶风是低饱和暖调，霓虹色与紫色渐变是反义词
- **charcoal**：炭笔偏西式素描，与水墨晕染冲突
- **gold foil**：烫金是"华丽感"，喜茶风要"朴素感"
- **3d render / anime style**：破坏纸面手作感
- **flat vector / minimalist line art**：太"设计感"，缺墨韵与纸性

## 六、文字规则

- 默认无图内文字（andiii 工作流原则，文案由公众号排版承载）
- 仅用户明确要求时加字：书法字 / 宋体竖排短句 + 印章落款（朱砂小红印）
- 文字低对比、半可读、不超过 6 字；文字本身当图形，不抢主体

## 七、情绪词表

静谧、温润、清冷、松弛、怀旧、留白、节气感、独处、雨天、时光流动、疏离、安静

## 八、质检门自检口诀

纸感词 ≥1 → 纹理词 ≥2 → 画布比例声明 → 硬规避全部以"避免"前缀豁免 → PASS 才生成。
